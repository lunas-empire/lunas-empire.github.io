## P0 gates still open

1. **New scores are not imported by image archival.** The tracker README says the post-OCR step archives originals and links a source only if a separately imported score matches name, exact value, week, and day. This frontend has private evidence/review endpoints for existing records but no established verified score-import API. A new screenshot can therefore arrive in the private archive without a new member value appearing in Luna. Implement or authorize the separate backend import/reconciliation contract before claiming an end-to-end import.
2. **The two unclear records remain unclear.** No authenticated current D1 query or original comparison was performed here. Do not turn either into zero. The review UI exposes individual source/day/member context when the API supplies it; a missing date or row coordinate cannot be invented by the client. Confirm both cases individually from their originals, persist through the authorized review endpoint, reload, and inspect the audit log.
3. **Historic active drivers still lack verified member IDs.** Neither ride is counted in a real active profile yet. An officer must use an original proof and an actual roster ID; similar spellings and corrupt OCR are insufficient. Confirm the Worker accepts a revisioned historical repair without changing the original source name, then reload the profile and train audit. The v50 active/former classification is already implemented; this candidate does not claim to discover those IDs.
4. **Worker staging is older than the frontend source.** No Wrangler authentication was available and no backend deployment or current D1 write was attempted. Verify `/api/session.reviewWritesEnabled`, role permissions, evidence endpoints, train revision handling, and audit entries in an authorized staging session after the separate backend release. A local synthetic success is not a live API or D1 acceptance.
5. **Device and language acceptance:** a real R4 and R5 must use mobile Safari on a physical iPhone (touch, keyboard, zoom, focus and file picker), including Arabic RTL and long labels. Automated dictionaries and Chrome/Edge emulation do not establish native fluency or Safari behavior.

No private canon backlog was present in this worktree. The tracker README and `OCR_UPLOAD_HINWEISE.txt` were consulted read only; `--prepare-only` was not run in the dirty tracker because it can create private output.
